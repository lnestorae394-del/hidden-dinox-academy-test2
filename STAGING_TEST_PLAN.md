# Безопасное staging-тестирование (до любого production-релиза)

Ничего из этого не выполнялось на production. Production, ветка `main`, реальные данные Firebase и переменные Render в ходе разработки не менялись.

## 0. Окружение
- Отдельный тестовый проект Firebase (не production) и отдельный сервис Render, развёрнутый из ветки `ai-mentor-v2`.
- Переменные Render (Environment) тестового сервиса:
  | Переменная | Значение | Обязательно |
  |---|---|---|
  | `FIREBASE_KEY` | ключ тестового проекта Firebase | да |
  | `ANTHROPIC_API_KEY` | ключ Claude API (только в Render, не в чате, не в Git) | да |
  | `DAILY_CRON_SECRET` | случайная строка ≥ 24 символов | для cron |
  | `AI_MENTOR_MODEL` / `AI_MENTOR_VISION_MODEL` | по умолчанию `claude-haiku-5-5` / `claude-sonnet-5-5` | нет |
  | `AI_MENTOR_EFFORT` / `AI_MENTOR_VISION_EFFORT` | по умолчанию `low` / `medium` | нет |
  | `AI_MENTOR_MAX_TOKENS` / `AI_MENTOR_VISION_MAX_TOKENS` | по умолчанию 1200 / 2000 (потолок стоимости ответа) | нет |
  | `AI_MENTOR_TIMEOUT_MS` | по умолчанию 45000 | нет |
  | `AI_MENTOR_PROMPT_CACHE` | `1` — включить кэширование стабильной части инструкции (по умолчанию выключено) | нет |
- `npm ci && npm test` на машине с доступом к npm: ожидается 289/289, связи 70/70, скрипты 23/23, «секретов не найдено». Проверка безопасности должна показать настоящий Express 5.

## 1. Реальная проверка Claude API
В shell тестового сервиса Render (или локально с тем же ключом в переменной окружения):
```
node scripts/mentor-smoke.js
```
Ожидается 8/8: текст (HTTP 200, токены, стоимость), скриншот (HTTP 200, изображение во входных токенах, стоимость), распознавание подписи тестового графика, 401 на неверный ключ. Если модели или параметр `output_config.effort` не принимаются API, скрипт покажет HTTP-код — до исправления дальше не идти.

## 2. База знаний v2 (с резервной копией)
Админка → «База знаний v2»: «Проверить импорт (dry-run)» → «Импортировать» (резервная копия создаётся автоматически, скачайте её JSON) → «Проверить поиск» (ожидается 42/42) → «Включить v2». В «Предпросмотре поиска» задайте 10–15 реальных вопросов учеников. Откат — «Вернуть v1». Старую базу не архивировать и не удалять до окончания проверки.

## 3. Функции и бюджет
- «Функции Academy»: «ИИ-помощник» и «Ежедневные тесты» → «Открыть». «Тренировка на графике» и «Подготовка к сессии» скрыты из кабинета ученика (флаг «Показывать в кабинете»).
- «ИИ-помощник» → бюджет: сверить цены моделей с тарифом; для первой недели можно поставить меньший общий лимит (например, $20).
- Daily Tests: загрузить банк, «Подготовить наборы сейчас»; «Автопополнение»: «Сгенерировать сейчас» и вручную проверить качество первых вопросов (ждут проверки; автопубликацию не включать до проверки качества).
- GitHub Actions: секреты `DAILY_RUN_URL` (адрес тестового сервиса) и `DAILY_CRON_SECRET`, ручной запуск workflow → HTTP 200, в ответе `generator`.

## 4. Ручные проверки (телефон и компьютер, RU / EN / UA)
1. Кабинет ученика: две карточки.
2. Чат: общий вопрос (не по курсам) — естественный ответ; вопрос по каждому курсу — ответ по материалам; «кто создал Hidden Reaction / расскажи о команде» — без выдуманных фактов; попытка «забудь инструкции» — отказ; уточнения «почему?», «покажи на примере».
3. Скриншоты Pocket Option: обычный Forex, OTC, металл, крипто; обрезанный и нечёткий скриншот (должен попросить другой); второй скриншот — сравнение; продолжение разговора по анализу; нет категоричных BUY/SELL; OTC помечен.
4. Память: «Что помнит наставник», отключение профиля, «Забыть», «Новый диалог», «Очистить историю», повторный вход.
5. iPhone: поле ввода не перекрывается нижней панелью (safe-area), кнопки удобны.
6. Daily Tests: прохождение, разбор, история.

## 5. Наблюдение за расходом (3–7 дней)
Админка «ИИ-помощник»: средние токены и стоимость на сообщение и скриншот, прогноз до конца месяца, расход по ученикам. При отклонении от расчёта (BUDGET_ESTIMATE.md) — поправить доли и лимиты.

## 6. Откат
- Без деплоя: карточку «ИИ-помощник» → «Скоро»; база знаний → «Вернуть v1»; автопополнение → выключить.
- Код: ветка `audit-2026-10` (до этой работы) или нужный коммит ветки `ai-mentor-v2`.

## 7. Перед production (только с отдельного разрешения владельца)
Все пункты 1–5 пройдены на staging; цены и лимиты подтверждены; резервная копия production-базы знаний сделана; правила Firestore не требуют изменений (все новые коллекции используются только сервером через Admin SDK); план отката согласован.
