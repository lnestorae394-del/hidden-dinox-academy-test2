## 2. Установка и локальный запуск

```bash
npm ci                                  # Node.js 18+
cp .env.example .env                    # заполните реальными значениями ТОЛЬКО локально; .env в .gitignore
node server.js
```
Без настоящего Firebase — тестовый режим на эмуляторах: см. `TEST_DEPOSIT.md`.

Проверки:
```bash
npm test                                # сервер: 136 тестов; запуск server.js; скрипты; поиск секретов
sh tests/run-all.sh                     # + браузер (Python 3 + Playwright): академия, админка, полный курс, загрузка, баннеры/читалка/партнёры
python3 tests/mutation-check.py         # 88 защит ломаются по одной — тесты обязаны поймать каждую
FAKE_FS_LATENCY=150 python3 tests/e2e/measure_load.py   # замер появления курса (модель задержки Firestore)
```

## 3. Настройки, которые делаете вы

**Render → Environment** (значения не публикуйте):

| Переменная | Нужна | Зачем |
|---|---|---|
| `FIREBASE_KEY` | да | сервисный аккаунт `ai-boost-10540` |
| `POCKET_POSTBACK_SECRET` | да | проверка postback |
| `POSTBACK_DEFAULT_CURRENCY` | по ситуации | `USD` после подтверждения от Pocket Partners |
| `REFERRAL_MODE` | нет | `off` по умолчанию; `test` — тестовые начисления; `live` — только после п. 5 |
| `ADMIN_BOOTSTRAP_UID` | нет | одноразовое назначение Super Admin |
| `FIREBASE_STORAGE_BUCKET`, `TELEGRAM_BOT_TOKEN`, `FIREBASE_PROJECT_ID` | нет | см. `ADMIN_PANEL.md` |

**Firebase:** правила для новых коллекций — `firestore.rules.academy-proposal` (клиентам запрещено всё; работа только через сервер). Применяйте после проверки на эмуляторе. Новые коллекции: `reading_progress`, `ref_codes`, `referral_invites`, `ledger`, `partner_balances`, `withdrawals`. Существующие коллекции и поля не переименовывались; в `users` добавляются `ref_code` и `referred_by`, в `announcements` — поля баннера (`kind` и др.; старые афиши считаются `kind: "poster"`). Миграций нет.

**Книга в репозитории:** PDF лежит в `private/books/` и выдаётся только через сервер. Но если репозиторий GitHub **публичный**, файл доступен там всем. Сделайте репозиторий приватным или храните PDF вне репозитория (например, Firebase Storage) — скажите, переделаю выдачу.

## 4. Проверка на staging (по порядку)

1. Ветку `feature/book-reader` — на отдельный staging-сервис Render. `hidden-dinox-academy-test2` пишет в production-Firestore; для staging лучше отдельный проект Firebase.
2. «Админка → Диагностика»: коммит совпадает с веткой, формат графиков исправлен, курс Hidden Reaction — 6 модулей / 29 уроков.
3. Главная: обновите страницу несколько раз — секция «Обучение» видна сразу (заглушка), курс появляется без исчезновения. DevTools → Network → `/api/learn/courses` → заголовок `Server-Timing` покажет время сервера.
4. Баннеры: «Читать книгу» → читалка, листание, перезагрузка → та же страница. «Мой кабинет» → ссылка.
5. Реферальная цепочка: откройте ссылку `?ref=` в другом браузере, зарегистрируйтесь → у партнёра «Приглашено: 1».
6. Регрессия: вход, Trader ID, страница депозита, админка, курс.
7. `REFERRAL_MODE=test` — проверить заявки и админку выплат; `live` — только после п. 5.

## 5. Что нельзя включать без вашего решения

- **Реальные начисления и выплаты** (`REFERRAL_MODE=live`): проверьте условия Pocket Partners (мотивированный трафик, перераспределение комиссии) и способ выплаты на счёт Pocket Option; нужна юридическая проверка (Германия). API выплат не реализован и не придуман: «Выплачено» отмечает администратор вручную с номером платежа.
- **Перевод курса Hidden Reaction на EN/UA:** не выполнялся; уроки, тесты и объяснения — на русском. Это отдельная работа с проверкой каждого вопроса.
- **Управление разделами академии (AI assistant, Tests, Chart practice) из админки:** не реализовано — сейчас это статичные карточки «Скоро» в `academy.html`.
- **Английская версия книги:** файла нет; читалка открывает русскую версию 1.0.
