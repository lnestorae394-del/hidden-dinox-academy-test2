## 8. Ваши шаги
1. Залить проект (содержимое архива) в репозиторий и задеплоить на Render (лучше сначала staging).
2. **Firebase Storage:** Console → Build → Storage → включить; роль *Storage Object Admin* для сервисного аккаунта; при другом бакете — `FIREBASE_STORAGE_BUCKET`. Проверка: «Админка → Диагностика».
3. **Переводы для уже импортированного курса:** «Админка → Импорт курса → Обновить переводы» → файл `content/hidden-reaction-course.json` → галочка → «Обновить переводы» → затем откройте курс и нажмите «Опубликовать». Повторный импорт курса не нужен.
4. **Тест начислений:** `REFERRAL_MODE=test`, `REFERRAL_PAYOUTS_ENABLED=1`.
5. **Реальные начисления** — только после проверки условий Pocket Partners: `REFERRAL_MODE=live` + `REFERRAL_LIVE_CONFIRMED=1` + `REFERRAL_PAYOUTS_ENABLED=1`.
6. **Firestore Rules:** применить `firestore.rules.academy-proposal` (после проверки на эмуляторе).
7. Если у ссылок Pocket Partners другой домен — добавить в `POCKET_LINK_HOSTS`.
