HIDDEN DINOX ACADEMY — TELEGRAM BOT UPDATE

ЗАМЕНИТЬ В GITHUB ТОЛЬКО 3 ФАЙЛА:
1) bot/core.js
2) bot/index.js
3) tests/bot.test.js

НЕ ЗАГРУЖАТЬ ПАПКУ ПРОЕКТА ЦЕЛИКОМ. Не менять server.js, package.json, package-lock.json, Firebase, торговую систему, реферальную систему и академию.

ЧТО ИЗМЕНЕНО
- /start отправляет стартовое видео только по Telegram file_id, без повторной загрузки MP4 с Render.
- Под видео добавлена подпись и две inline-кнопки: открытие Hidden Dinox Academy и поддержка.
- Настраивается синяя Telegram Menu Button «Открыть Hidden Dinox Academy» рядом с полем ввода.
- Если стартовый file_id ещё не настроен или Telegram его отклоняет, бот не пытается загружать локальный MP4; он отправляет текстовый fallback с кнопками и пишет ошибку в лог.
- Администратор может обновить стартовое видео командой /videoid (или /setstartvideo), затем отправить видео следующим сообщением именно как видео, не как документ. Новый file_id сохраняется в Firestore bot_config/start_video и имеет приоритет над BOT_START_VIDEO_FILE_ID.
- Сохранён существующий мастер постов и ручной рассылки.

НАСТРОЙКА СТАРТОВОГО ВИДЕО
1) После Deploy открой личный чат с ботом с аккаунта, чей числовой ID указан в ADMIN_TELEGRAM_ID.
2) Отправь /videoid.
3) Следующим сообщением отправь MP4 как видео (не как файл/документ).
4) Бот подтвердит сохранение file_id.
5) Проверь /start с другого аккаунта или тестового пользователя.

УПРАВЛЕНИЕ ПУБЛИКАЦИЯМИ (ТОЛЬКО ADMIN_TELEGRAM_ID)
/newpost — создать пост пошагово.
Далее отправь текст, затем фото/видео или /skip, затем кнопки или /skip.
Формат кнопок: Название | https://example.com
Несколько кнопок в одном ряду: Название 1 | https://example.com || Название 2 | https://example.org
/posts — список публикаций.
/editpost ID — изменить только черновик.
/deletepost ID — удалить после подтверждения.
/broadcast ID — предпросмотр и запрос подтверждения. Рассылка стартует только после нажатия кнопки подтверждения.
/cancel — отменить текущий мастер.

ПОВЕДЕНИЕ РАССЫЛКИ
- Нет расписания, таймера или автоматической публикации новых постов.
- Новая рассылка требует команды администратора /broadcast и явного подтверждения кнопкой.
- Если администратор уже подтвердил рассылку и процесс Render перезапустился посреди неё, незавершённая рассылка может продолжиться после запуска сервера. Существующие delivery-записи защищают от повторной отправки одному и тому же пользователю.
- Telegram-бот может писать только пользователям, которые ранее нажали Start и не заблокировали бота.

ПЕРЕМЕННЫЕ RENDER НЕ МЕНЯТЬ, ЕСЛИ ОНИ УЖЕ НАСТРОЕНЫ:
BOT_ENABLED=1
TELEGRAM_BOT_TOKEN=токен бота
ADMIN_TELEGRAM_ID=числовой Telegram ID администратора
BOT_WEBHOOK_URL=https://hiddendinox.com/telegram/webhook
BOT_WEBHOOK_SECRET=секрет не короче 24 символов
Необязательно: BOT_WEBAPP_URL (по умолчанию https://hiddendinox.com), BOT_SUPPORT_URL (по умолчанию https://t.me/hiddendinoxsupport).
