# Итог (этап F)

## Что из реальных материалов использует система
- AI Mentor (база v2, после включения): разделы и термины уроков трёх курсов на RU/EN/UA, 46 страниц книги «The Hidden Reaction System» на каждом языке, сведения о проекте (только заявления владельца). До включения v2 — прежний путь: опубликованные уроки + `hd_knowledge`.
- Генератор Daily Tests: тексты опубликованных уроков (кроме уроков-тестов и блоков тестов), с обязательной дословной цитатой-обоснованием.
- Память наставника: прогресс уроков, результаты тестов уроков, ошибки Daily Tests и тренировки на графике — из данных ученика, без запросов к ИИ.

## Что НЕ является «полной базой» и остаётся пробелом
1. Сведения о Hidden Dinox, основателе и команде — только формулировки владельца проекта (5 записей); EN/UA — черновики до проверки администратором. Биографии, имени, истории, продуктов, цен, статистики в материалах нет и не добавлялось.
2. Психология трейдинга, криптовалюты, Forex, общие рынки — отдельных материалов в проекте нет; наставник отвечает из общих знаний с пометкой «общее объяснение», не как правило Hidden Dinox.
3. 60 вопросов HR в банке без объяснений (в источнике — ссылки на страницы книги); связь «урок ↔ страницы книги» теперь есть, объяснения нужно дописать в редакторе банка.
4. 4 вопроса банка типа «график» без изображения; генератор не создаёт вопросы с изображениями.
5. В курсе SMC нет отдельного общего определения «Order Block» (есть bullish / bearish OB).
6. Качество поиска оценено на 62 вопросах, составленных разработчиком; на реальных вопросах учеников его нужно наблюдать через «Предпросмотр поиска».
