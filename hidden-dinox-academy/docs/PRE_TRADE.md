# Pre-Trade Routine и Session Summary

## Маршрут (на текущую дату Europe/Berlin)
1. **Повторение** — модули и уроки, где были ошибки за последние 7 дней (неверные ответы Daily Tests, пропущенные факторы и ошибки в Chart Training). Ученик отмечает «Повторил материал». Без ошибок — предложение повторить последний пройденный урок.
2. **Daily Tests** — «Готово», когда пройдены все задания сегодняшнего набора (по сохранённым ответам). Если набора ещё нет, он создаётся из банка так же, как на странице Daily Tests (один раз, без дублей).
3. **Chart Training** — «Готово», когда сегодня разобран хотя бы один сценарий.
4. **Итог подготовки** — результат тестов, практики (средний балл), основные ошибки (темы, пропущенные факторы), рекомендуемые уроки, дата последней завершённой подготовки; «Завершить подготовку» — после всех доступных этапов.

- Маршрут можно прервать и продолжить: состояние этапов вычисляется из данных модулей. Хранится только отметка «повторил» и завершение (`pretrade_runs/{uid}__{дата}`).
- Модуль, выключенный в «Функциях Academy», отображается как «Недоступен» и не блокирует завершение.
- Доступ к курсам не зависит от результатов. Страница не обещает прибыль и не называет ученика «готовым к торговле».

## Включение
Админка → Функции Academy → «Pre-Trade Routine» (четвёртая стандартная карточка) → «Открыть». Для полного маршрута также откройте Daily Tests и Chart Training.

## API
Ученик (доступ как к курсам + карточка «Открыть»): `GET /api/routine/today?lang=ru|en|ua`, `POST /api/routine/mark` с `step` = `start` | `review` | `complete` (завершение — только после доступных этапов, иначе 409).

## Откат
Без деплоя: карточку «Pre-Trade Routine» → «Скоро». Кода: коммит до этапа 4 (`ed4115f`).
