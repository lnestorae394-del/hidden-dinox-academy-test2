# Функции Academy — карточки AI Mentor, Daily Tests, Chart Training

## Для администратора
Админка → **Функции Academy** (право `features.manage`, роль admin и выше). Изменения видны ученикам сразу, без деплоя.
- Статусы: «Открыть» (ACTIVE), «Скоро» (COMING_SOON), «В разработке» (IN_DEVELOPMENT), «Отключено» (DISABLED — скрыть или показать с меткой).
- Тексты RU / EN / UA; пустой перевод → русский текст. Иконка из набора, порядок (↑/↓), включена/выключена, предпросмотр, «Отмена» не сохраняет.
- «+ Карточка» — дополнительная информационная карточка (без страницы). «Вернуть стандартные» — исходные тексты и «Скоро» для трёх стандартных; дополнительные не меняются.
- «Открыть» недоступен, пока у модуля нет реализованной страницы — так ученик не попадёт на несуществующую страницу.

## Для разработчика: подключение модуля
1. Реализовать страницу модуля, например `public/academy/daily-tests.html`.
2. В `academy/features.js` → `MODULES["daily-tests"].href = "/academy/daily-tests.html"`.
3. В каждом API модуля проверять доступ: `await features.requireFeature("daily_tests")` → 403 `FEATURE_UNAVAILABLE`, если карточка не «Открыть» или выключена.
4. После деплоя администратор переводит карточку в «Открыть».
Ссылки карточек берутся только из `MODULES` — произвольных адресов в настройках нет.

## Данные и API
- Firestore: `academy_features/{id}` — только правки; стандартные карточки заданы в коде (`DEFAULTS`).
- Ученик: `GET /api/home/features?lang=ru|en|ua` (доступ как у курсов).
- Админка: `GET/POST /admin/api/features`, `PUT /admin/api/features/:id`, `POST /admin/api/features/:id/status`, `POST /admin/api/features/order`, `POST /admin/api/features/:id/delete` (с `confirm`), `POST /admin/api/features/reset` (с `confirm`). Все действия — в журнале аудита (`feature.*`).

## Откат
- Без деплоя: «Вернуть стандартные» или удалить документы `academy_features` — главная покажет стандартные карточки «Скоро».
- Кода: вернуться к коммиту до этапа 1 (`24d9ed9`). Существующие коллекции этап 1 не меняет.
