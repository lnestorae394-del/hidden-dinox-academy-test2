# Автопополнение банка Daily Tests (ИИ)

## Как работает
- Запускается из существующего cron `POST /internal/daily/run` (GitHub Actions) после подготовки наборов на сегодня и завтра. Ошибка генерации не мешает наборам: они строятся из одобренного банка.
- Генерация идёт только для курсов, где запас меньше порога (по умолчанию 7 дней), до целевого запаса (по умолчанию 10 дней, допустимо 7–14), не больше 12 вопросов за запуск и не чаще раза в день. Ручной запуск в админке — в любой момент (если запас в норме, сообщает «генерация не нужна»).
- Параллельные запуски исключены блокировкой в Firestore (`daily_generator/state`, снимается через 10 минут). Каждый запуск пишется в `daily_generator_runs`.
- Источник — опубликованные и видимые ученикам уроки Hidden Reaction, SMC и Risk Management (кроме уроков-тестов). Чаще берутся уроки, по которым в банке меньше вопросов.
- Модель — `claude-haiku-5-5`, усилие `low`, по 3 вопроса за вызов. Расход — доля «Daily Tests» бюджета ИИ ($10 по умолчанию) с резервированием; при исчерпании генерация останавливается.

## Проверки каждого вопроса (на сервере)
Схема и тип; 3–5 уникальных вариантов; корректный индекс правильного ответа; объяснение правильного ответа и объяснение каждого неверного варианта; запрет «все перечисленные» / «ни один из»; цитата из урока (source_quote) действительно есть в тексте урока; нет дубля и почти-дубля (сходство слов ≥ 0,75) в банке курса; переводы EN/UA на правильном языке (неверный перевод отбрасывается, вопрос остаётся на русском).

## Что сохраняется
`source: ai_generated`, `source_material_ids` (ID урока и его адрес в курсе), `model`, `difficulty` (beginner / intermediate / advanced), тип, `source_ref` с цитатой, `translation_status` EN/UA (`draft` или `missing`), `review_status`.
По умолчанию — `status: needs_review`, `review_status: pending_review`: в наборы вопрос не попадает, пока администратор не одобрит его в банке (одобрение → `approved`, отключение → `rejected`).
Автопубликация — отдельный переключатель; публикуются автоматически только вопросы без единого замечания. Переводы при этом остаются черновыми.

## Админка → Daily Tests → «Автопополнение банка (ИИ)»
Одобрено, ждут проверки (кнопка «Показать» открывает их в банке), сгенерировано / одобрено / отклонено, запас в днях по курсам, последний запуск, ошибки, расход; настройки; «Сгенерировать сейчас». Фильтр «Источник» в банке: вопросы курсов / ИИ-генерация.

## Отключение
Снять «Автопополнение включено» в админке — cron продолжит готовить наборы из банка без генерации.
