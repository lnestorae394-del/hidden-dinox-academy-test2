# Chart Training — тренировка анализа графика (без ИИ)

## Как устроено
- Ученик получает сценарий: только видимую часть графика. Отвечает: гипотеза (вверх / вниз / нет сделки), факторы (структура, снятие ликвидности, BOS/MSS, FVG, Premium/Discount, нет подтверждения), уровень отмены (щелчком по графику), учебный вход, риск %, объяснение.
- После фиксации ответа сервер раскрывает следующие свечи и даёт разбор по 4 критериям (по 25 баллов): гипотеза относительно контекста, найденные факторы, уровень отмены (сторона и разумное расстояние), риск (≤ 2% — полный балл).
- Оценивается аргументация, а не исход: «обоснованная гипотеза, которая не реализовалась» — не ошибка; «нет сделки» в диапазоне — верное решение; сделка в диапазоне — «лучше было пропустить».
- Ответ фиксируется один раз; история и повторный разбор — вкладка «История». Ученик видит только свои тренировки.

## Сценарии
- 12 встроенных симуляций (5 типов: тренд вверх/вниз с откатом, снятие ликвидности с разворотом вверх/вниз, диапазон). Свечи строятся генератором из seed — одинаковые при каждом открытии. Всегда помечены «Симуляция — не реальные рыночные данные».
- Исторические — импорт CSV в админке (Chart Training → «Импорт CSV»): столбцы Time (или Date), Open, High, Low, Close; 30–400 строк; обязательны инструмент, таймфрейм и источник данных (откуда файл и разрешено ли учебное использование); число видимых свечей; ожидаемая гипотеза и факторы. Сервер проверяет порядок времени и корректность OHLC. Ученику показывается пометка с инструментом, таймфреймом и источником.
- Сценарий можно отключить галочкой «Активен»; история учеников при этом сохраняется. Платные источники данных не подключены.

## Включение
Админка → Функции Academy → Chart Training → «Открыть». До этого страница и API закрыты для учеников (сотрудникам — предпросмотр).

## API
Ученик: `GET /api/chart/next`, `POST /api/chart/answer`, `GET /api/chart/history`, `GET /api/chart/session/:id`.
Админка (право `chart.manage`): `GET /admin/api/chart/scenarios`, `GET /admin/api/chart/scenarios/:id`, `POST /admin/api/chart/scenarios/:id/status`, `POST /admin/api/chart/import`.
Firestore: `chart_scenarios` (отключения и CSV-сценарии), `chart_sessions` (ответы и разборы).

## Ограничения первой версии
Разбор — по заданным критериям сценария, без ИИ: свободный текст объяснения сохраняется, но не анализируется. Разбор ИИ можно добавить позже вместе с AI Mentor.

## Откат
Без деплоя: карточку Chart Training → «Скоро». Кода: коммит до этапа 3 (`35e9e86`).
