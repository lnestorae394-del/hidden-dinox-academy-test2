# Hidden Dinox Academy — исправление корневого маршрута

## Изменения

- `server.js`: GET `/` отдаёт существующий `public/academy/index.html` напрямую. Редиректа на `/academy/index.html` нет.
- `academy/root-page.js`: добавляет `<base href="/academy/">` для корректной загрузки CSS, JavaScript и изображений; ссылка логотипа возвращает на `/`.
- `public/academy/js/config.js`: переходы между этапами входа, брокера, депозита и академии используют абсолютные URL `/academy/...`, поэтому работают и с чистого `/`.
- `public/academy/js/api.js`: переход на страницу блокировки использует абсолютный URL.
- `tests/root-route.test.js`: добавлены проверки чистого корневого URL, базового пути ресурсов и внутренних переходов.
- `package.json`: новый тест включён в `npm test`.

## Проверки

- `node --check` для изменённых JavaScript-файлов — пройдено.
- `node --test tests/root-route.test.js` — 2/2 пройдены.
- `npm test` — 210/210 тестов пройдены; wiring checks, CLI checks и secret scan завершились успешно.
- Secret scan проверил 68 файлов, секретов не найдено.

## Ограничение проверки

Полный локальный запуск Express-сервера не состоялся, потому что `express` отсутствовал в локальном `node_modules`, а `npm ci` не завершился в доступное время. Поэтому HTTP-проверку живого процесса не заявляю как пройденную. После загрузки ZIP в репозиторий Render должен установить зависимости по `package-lock.json`.

## Безопасность деплоя

ZIP содержит исходный проект и исправление. Изменения не отправлялись в GitHub и не деплоились в Render. Настройки окружения, Firebase и ключи Render не изменялись.
