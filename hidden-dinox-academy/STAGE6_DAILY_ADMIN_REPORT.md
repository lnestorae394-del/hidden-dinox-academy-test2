# Stage 6 — Daily Tests: редактор банка и графические задания

## Реализовано
- В админке появилась форма создания вопроса Daily Tests.
- Поддерживаются курсы HR / SMC / Risk Management и типы choice, situation, term, error, chart.
- Проверяются текст вопроса, урок/модуль, 2–6 уникальных вариантов, индекс правильного ответа и объяснение.
- Новые вопросы всегда создаются со статусом `needs_review`; автоматически в ежедневные наборы не попадают.
- Для типа `chart` обязательно изображение из медиатеки Academy. Принимается только внутренний путь `/media/med_<20 hex>`.
- Загрузка изображения использует существующий защищённый endpoint медиатеки и Firebase Storage; сервер проверяет MIME, сигнатуру и размер.
- Изображение сохраняется в опубликованный ежедневный набор и отображается ученику в задании и разборе.
- Администратор может проверить вопрос, затем одобрить или отключить его существующими действиями банка.
- Добавлен тест на валидацию, media ID и обязательный статус ручной проверки.

## Ограничения
- Новые вручную созданные вопросы пока вводятся на русском языке. EN/UA переводы не генерируются автоматически и не выдумываются.
- Для загрузки графического файла должен быть настроен Firebase Storage. Если он не настроен, админка покажет ошибку загрузки; вопрос не будет создан.
- Это обычное изображение-иллюстрация. Интерактивный график со свечами, точками ответа и временной шкалой не входит в этот этап.
- Вопросы, которые уже включены в опубликованный daily_set, остаются неизменными; редактирование банка влияет только на будущие наборы.
